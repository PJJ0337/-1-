# 손목 2축 예측 분석 (1쪽) — 모델 변경 없이 근거만 · week09 박종진

**질문** 팔이 4-DOF(A1 확정, 가정값 S13)라 수직 하강 집기에서 「위치 3 + 그리퍼 축 2 + 손가락 방향 1 = 6조건」을 팔만으로 못 맞춘다. 손목 2축이 있었다면 IK 수렴률 · 집기 성공률이 어떻게 달라지나? — A팀 · 팀장 판단(손목 추가 여부)의 근거 자료. **v1 모델 · MJCF는 바꾸지 않음**: 지금 팔의 플랜지(tool0) 자세만 쓰고 손목은 수식으로 덧붙여 계산.

**가정** 손목 = pitch(tool0 x축, ±90°) → roll(그리퍼 축, ±180°), 그리퍼 · 손가락은 지금과 같음(tool0 → ee 0.10 m), 손목 모듈 길이 L_w 0 / 0.06 m, 손목 질량 0.8 kg(소형 서보 2개 + 브래킷 — **근거 없는 가정**, A팀 후보 부품 오면 교체). 자유도 = 팔만 4 → 6, 전신 7 → 9.

**방법** (`b1/models/v1/scripts/wrist_predict.py`, ~3 분) 7주차 workspace_wb ④와 같은 방식 — 무작위 팔 2만 자세를 수직 하강 조건 위로 Gauss-Newton 투영 · 자기 충돌 제외. 지금 = 플랜지 z축 = 연직(2식), 손목 = 플랜지 x축 ⟂ 연직(1식, pitch θ = atan2(−a, b) 범위 안). 7주차와 같은 150목표로 팔만 IK도 직접 풀었음.

**집기 성공률 예측** (지금 = 8주차 무작위 20회 19/20, 9주차 평가 50회 49/50)
- 실패 2건 모두 손목으로 풀리는 종류: ① 8주차 seed 1 = 상자 yaw 40° · 깊이 0.212 m ik_fail — 손가락 방향을 roll로 맞추면 상자 = 원기둥 조건(원기둥은 0.24 m까지 7/7) ② 9주차 seed 2002 = 원기둥 깊이 0.214 m 계획 실패 — 옆면 깊이 여유가 +0.11 ~ 0.15 m 늘어남. → **현재 생성 범위(깊이 0.06 ~ 0.22 m)에서는 20/20 · 50/50 예상**(예측 — 모델 · 상태기계를 바꿔 측정한 값 아님).
- 계획 도달 한계: 8주차 실제 0.24 m(테이블 여유 · 경로 점검 포함, 이상값 0.30 m보다 0.06 m 짧음) → 같은 손실을 빼면 손목 **약 0.35 ~ 0.39 m**.
- 정면 접근이 깊이 ~0.10 m까지 가능 → 가까운 물체는 베이스 −90° 회전 · 경유점 후진이 필요 없음. 지금 APPROACH 9.2 s(에피소드 24.6 s의 37 %)가 줄고, **9주차 BC가 실패한 구간(경유점에서 멈춤 · 회전 중 오차 누적)이 짧아짐** → BC에도 유리할 것으로 예상.

**비용 — 토크** 손목 0.8 kg을 어깨에서 0.475 m(상완 0.276 + 전완 0.199): +3.73 N·m, 3 kg 짐이 L_w만큼 멀어짐: +1.77 N·m → 파지 중 필요 pitch 48.69 → **52.42 ~ 54.18 N·m**, PDR 52 N·m 여유 6.8 % → **−0.8 ~ −4.0 %**(기준 20 %). 정격 TQ 118.8 N·m case면 통과. 즉 **손목 추가 = 어깨 구동기 TQ 확정(또는 짐 2 kg 제한)과 같이 결정해야 함**.

**결론** 손목 2축은 IK 조건 수(6) = 팔 자유도(6)로 만들어 수직 하강 가능 영역을 4.6 ~ 6.7배, 테이블 도달 깊이를 +0.11 ~ 0.15 m 늘리고 지금 실패 2건을 없앨 것으로 예측된다. 다만 높이 대역 아래쪽(상판 위 0.2 m 이하 · 바닥)은 손목으로도 거의 안 바뀌고(0.605 → 0.545 m), PDR 52 기준 토크는 더 부족해진다. **한계**: 손목 기구 · 범위 · 질량은 가정, 테이블 ↔ 팔 링크 충돌과 손목 자체 충돌은 미검사(끝점 기준 상한), 제어 · 접촉은 시뮬하지 않음.
