## Q1. DLS에서 λ를 키우면 / 줄이면 특이점 근처와 정확도는 어떻게 달라지는가

- DLS: dq = Jᵀ(JJᵀ + λ²I)⁻¹ e. SVD로 보면 특이값 σᵢ 방향 이득이 1/σᵢ(의사역행렬) 대신 **σᵢ / (σᵢ² + λ²)**
  - σ ≫ λ: ≈ 1/σ → 의사역행렬과 같음(빠르고 정확)
  - σ → 0(특이점): 의사역행렬은 1/σ → ∞(관절 속도 폭주), DLS는 σ/λ² → 0으로 눌러 줌. 최대 이득 = 1/(2λ) (σ = λ에서)
- **λ ↑**: 특이점 근처 안정(스텝 작음) · 대신 수렴이 느리고, 매 반복 해가 「최소자승 + λ²‖dq‖²」 타협이라 목표 쪽으로 덜 감 → 허용오차까지 반복이 늘어남
- **λ ↓**: 멀리서는 빠르지만 특이점 근처에서 dq가 커져 튐 · 진동, 관절 한계 클리핑과 겹치면 정체
- 우리 숫자 (왼팔, 재시작 없음, 스텝 제한 0.3 rad):

| λ | T7 편 팔(특이점 근처) 반복 · 원 스텝 최대 | T9 도달 밖 원 스텝 최대 | T5 머리 위 |
|---|---|---|---|
| 0.005 | 14회 · 20.3 rad | 20.2 rad, 마지막 20회 2.2 mm 진동 | 관절 한계에서 정체 48 mm |
| 0.05 (기본) | 16회 · 3.1 rad | 2.3 rad, 0.95 mm | 정체 (재시작 1회로 수렴) |
| 0.3 | **133회** · 0.74 rad | 1.0 rad, 진동 0 | 30회 수렴 |

  - 「원 스텝」= 스텝 제한 전 ‖dq‖ — λ가 작으면 특이점에서 수십 rad까지 커짐(제한이 없으면 발산). λ = 0.3은 안정하지만 T7에서 반복 8배
  - 정확도: 수렴하면 허용오차(1 mm)로 같음. 차이는 「몇 번 만에」 와 「작업공간 밖에서 얼마나 얌전히 최근접 해로 가는가」
- 실무 대응: λ 고정 0.05 + 스텝 제한 + 재시작 4회(수렴률 99.6 %). 더 나은 방법 = 가변 λ(최소 특이값이 작을 때만 키움, Nakamura · Buss), 이번엔 구현 안 함

## Q2. 6-DOF 팔에서 위치만 IK할 때와 위치 + 자세 IK할 때 자코비안 크기와 해의 개수는

- 자코비안 = (과제 차원) × (관절 수)
  - 6-DOF 위치만: **3 × 6** → 여유자유도 3, 영공간 3차원 → 해 무한(연속 집합). DLS는 그중 시작점에서 가까운(최소 노름 변화) 해를 줌
  - 6-DOF 위치 + 자세: **6 × 6** 정방 → 특이점이 아니면 해는 유한 개(일반 6R 최대 16, 구형 손목 팔은 최대 8 — 어깨 좌우 × 팔꿈치 위아래 × 손목 뒤집기)
- **우리 팔은 4-DOF(손목 없음)** — 그래서 같은 질문이 더 날카로워짐
  - 위치만: **3 × 4** → 영공간 1차원 → 해 무한(팔꿈치가 어깨-손 축 둘레로 돌 수 있는 「self-motion」). 수렴률 **99.6 %**(500 목표)
  - 위치 + 그리퍼 축(2조건): **5 × 4** → 과결정 → 일반적으로 해 0. 해가 있는 점은 2차원 곡면뿐(축을 고정하면 팔꿈치 위치가 정해짐) → IK 표 X0~X2: 위치는 0.000 mm, 축은 1.8 ~ 21.7° 남음(`orientation_limit`)
  - 위치 + 자세 전체: **6 × 4** → 더 과결정
- 구현: axis 모드는 회전 자코비안을 현재 z축에 수직인 평면으로 투영(P = I − zzᵀ) → z축 둘레 회전(축 방향을 안 바꿈)은 오차로 안 셈. 동시 불가일 때 위치 등식 제약 하 축 오차 최소(SLSQP)
