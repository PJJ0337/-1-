# 04. v1 — 좌우 미러 · 홀로노믹 베이스 근사 (week05 구술 대비)

## Q1. 좌측 팔을 미러로 만들 때 axis 부호를 바꾸는 관절과 안 바꾸는 관절은 어떻게 구분하는가

- 거울 변환 M = diag(1, −1, 1) (거울면 = base의 xz 평면, y = 0). **점 · 위치 · COM**은 그대로 M을 곱함 → y 부호만 반전
- **회전축은 유사벡터(축벡터)**: 거울상에서 회전 방향이 뒤집히므로 a' = det(M)·M·a = −M·a = (−a_x, a_y, −a_z)
  - → 거울면 **법선(y)과 평행한 축은 유지**, **거울면 안(x · z)에 있는 축은 반전**
- 우리 팔(영점 링크 프레임 기준): shoulder_pitch = +y → **유지**, shoulder_roll = +x → **반전(−x)**, shoulder_yaw = +z → **반전(−z)**, elbow = +x → **반전(−x)** — [mirror_rules.md](../../../../b1/models/v1/docs/mirror_rules.md)
- 같이 바뀌는 것: origin rpy는 roll · yaw 반전(pitch 유지) → shoulder_yaw 영점 rpy −π/2 → +π/2, 관성 텐서는 M I M → ixy · iyz 반전, 메시는 y 반전 + **면 winding 뒤집기**(안 하면 법선이 안쪽)
- 결과: **같은 관절각 명령 → 좌우 대칭 동작, 관절 범위도 양팔 같음**(안 A, 팀장 승인 10/16). 검증 ⑤: 504자세 |Δx| · |Δz| · |y_L + y_R| = 0 mm (생성식이 정확한 거울이라 0)
- 커리큘럼 말처럼 미러는 "메시 좌우 반전"이 아니라 **장착 프레임 + 축 방향** 문제 — 메시만 뒤집고 축을 그대로 두면 같은 명령에 한쪽은 안쪽, 한쪽은 바깥쪽으로 돈다
- 안 B(축을 world 기준 같은 방향으로)도 가능하지만 범위가 좌우 반대(roll −0.28~1.5 ↔ −1.5~0.28)가 되고 ICD v0 3.4와 어긋나 기각. 실제 모터 방향 차이는 B2 드라이버 계층 한 곳에서만 반전

## Q2. 옴니휠 대신 slide · slide · hinge로 베이스를 근사했을 때 잃는 것과 지금 단계에서 괜찮은 이유

- 근사: base_link가 평면 3-DOF(x · y · yaw) 관절 + velocity 액추에이터(kv)로 움직임. 높이 · roll · pitch 고정
- **잃는 것**
  1. 바퀴-바닥 **접촉력 · 마찰 · 슬립** — 가감속이 마찰 한계(μ·N)를 넘어 미끄러지는 현상 없음
  2. **전복 · 기울어짐** — 팔을 뻗거나 급가속해도 roll · pitch가 고정이라 ZMP/전복 여유를 볼 수 없음
  3. 휠 모터 토크 · 속도 한계, 롤러 진동 — velocity 액추에이터가 forcerange(±2000 N) 안에서 거의 이상적으로 따라감
  4. 팔 반력이 바퀴 하중 분배를 바꾸는 효과 (평면 내 반력은 액추에이터가 흡수)
- **괜찮은 이유**: 5 · 6주차 목표는 **팔 동역학 · 작업공간 · 토크 여유** — 베이스는 "평면에서 자유롭게 움직이는 받침"이면 충분. 옴니휠 롤러 접촉은 CPU에서 느리고 불안정. 하체 실측(질량 · COM · 바퀴 배치) 전이라 접촉 모델을 넣어도 숫자가 가정값
- 숫자: 베이스 1차 응답 시정수 τ = M / kv = 75.1 / 200 = **0.375 s** ↔ 시뮬 63 % 도달 **0.378 s**, yaw 0.082 s ([base_velocity_test.json](../../../../b1/models/v1/results/base_velocity_test.json)). yaw 88° 돈 뒤 body 기준 vx 0.5 → world 변환하면 body 속도 (0.495, −0.000) m/s (체크리스트 C3-2)
- 나중에: 하체 실측 후 freejoint + 힘 인가(C3-0) 또는 바퀴 4개 hinge + 접촉으로 전복 · 슬립 확인. Isaac Sim은 planar 미지원 → prismatic · prismatic · revolute 사본(b1_v1_isaac.urdf, 원본과 50자세 차 1e-15)
