## 이 저장소가 평가에 쓰이는 방식

주차별 평가표의 **④ 문서화 · 주차 보고(15점)** 는 이 저장소를 근거로 채점됩니다.

- **개인 기여 로그가 공유 저장소에 없으면 ④는 척도 1(3점)** 로 처리됩니다. (기획서 공통 원칙 ①)
- 척도 4 조건: 기한 내 제출 + **수치 · 파일 · 저장소 태그가 연결되어 재현 가능**
- 척도 5 조건: 타인이 그대로 이어받아 작업할 수 있는 수준, 절차서 · BOM · ICD 갱신에 기여
- 그래서 매주 **`weekNN` 태그**를 금요일 제출 시점 커밋에 붙이고, 주간 보고서의 「산출물」 칸에는 노션 페이지 대신 **이 저장소의 파일 경로 + 태그**를 적습니다.

작성 규칙은 [CONTRIBUTING.md](CONTRIBUTING.md)를 따릅니다.
