## 1. CAD 형상 포맷

| No. | 요청 | 이유 |
|---|---|---|
| 1.1 | 전체 조립품 **STEP(AP214)** 1부 + **링크 단위 메시** (STL 또는 OBJ) | URDF는 링크마다 메시 1개(visual) + 단순 형상/메시(collision)를 참조 |
| 1.2 | 링크 단위 메시는 **해당 링크 좌표계 원점 기준**으로 내보내기 (조립 원점 기준 X) | 조립 원점 기준이면 URDF `<visual><origin>`에 매 링크 오프셋을 따로 넣어야 함 |
| 1.3 | 단위 **m** (STL은 단위 정보가 없으므로 mm 출력 시 반드시 표기) | URDF · USD Physics · MuJoCo 모두 SI 단위 |
| 1.4 | visual용(고해상도)과 collision용(단순화, 링크당 ≤ 수천 폴리곤 또는 박스/원통 근사) 구분 | 충돌 연산 비용, Isaac Sim convex hull 품질 |
| 1.5 | 링크 = 하나의 강체로 움직이는 부품 묶음 기준으로 분리 (볼트 · 커버는 해당 링크에 병합) | 링크 수 = 강체 수 |

## 2. 질량 · 관성 제공 형식 (링크별 1행)

| 필드 | 단위 | 기준 |
|---|---|---|
| link_name | – | 4절 이름 규칙 |
| mass | kg | |
| com_xyz | m | **링크 좌표계** 기준 |
| inertia (Ixx, Iyy, Izz, Ixy, Ixz, Iyz) | kg·m² | **COM 기준, 링크 좌표계 축 방향** |
| source | – | `CAD`(재질 밀도 지정 여부 표기) / `실측` |

- CSV 1개로 제공 → B1이 URDF `<inertial>`로 자동 변환 (기획서 B1 「자동 갱신 파이프라인」)
- CAD 관성 출력 시 **출력 좌표계**(COM/링크 원점/조립 원점)를 반드시 표기 — 기준점이 다르면 평행축 정리로 값이 달라짐
- 관성 누락 금지: MuJoCo는 URDF에 `<inertial>`이 없으면 collision 형상과 밀도 1000 kg/m³으로 추정하고(실험: 0.2×0.1×0.1 m 상자 → 2.0 kg), Isaac Sim 구버전 임포터는 관성 누락 시 단위행렬을 쓴다고 문서화돼 있음 → 두 시뮬레이터 결과가 달라짐

## 3. 관절 좌표계 규약

| No. | 규약 (제안) |
|---|---|
| 3.1 | 오른손 좌표계, **x 전방 · y 좌측 · z 상방** (ROS REP-103), 베이스 좌표계 원점 = 바닥면 중심 |
| 3.2 | **영점 자세**: 팔을 아래로 곧게 내린 자세를 모든 관절 0 rad으로 정의 (도면에 명시) |
| 3.3 | 각 관절의 링크 좌표계 원점은 **관절 회전축 위**, 회전축은 가능하면 링크 좌표계의 x/y/z 단위축 중 하나에 정렬 |
| 3.4 | 양(+)의 회전 방향 = 회전축 방향 기준 오른손 법칙, 좌우 팔은 **거울 대칭**(roll · yaw 부호 반전)임을 표로 명시 |
| 3.5 | 관절별 제공: 부모 링크 → 자식 링크 변환(xyz [m], rpy [rad]), 회전축, 가동 범위 [rad], 기구적 스토퍼 위치 |

## 4. 링크 · 관절 이름 규칙

`{side}_{부위}_{운동}_link` / `{side}_{부위}_{운동}_joint` (G1 · ROS 관례)

| 예 | 비고 |
|---|---|
| `base_link` | 홀로노믹 베이스 루트 |
| `torso_link` | 상체 몸통 (허리 관절 있을 시 `waist_yaw_joint` 등) |
| `left_shoulder_pitch_joint` / `left_shoulder_pitch_link` | side = left/right |
| `left_elbow_joint` | 운동 방향이 하나뿐이면 생략 |
| `left_wrist_roll_joint` | |
| `imu_base_link`, `head_camera_link` | 센서 장착 프레임 (fixed joint) |

- 소문자 · 언더스코어만, 한글 · 공백 금지 (USD prim path 제약)
