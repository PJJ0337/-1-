## 3. 해석 (B1)

- 전문가는 **기준 궤적 + 측정 피드백 + 측정 기반 단계 전환**이라 동역학 차이를 흡수. BC는 「시연에서 본 상태 → 명령」 대응을 외운 것이라 **학습 때 없던 동역학(지연 · 질량 · 게인)과 관측 분포 밖(테이블 높이 1개 → obj_z)** 에서 무너짐 = 공변량 이동이 랜덤화로 드러남
- 지연: 청킹 시간 앙상블은 「지금 상태 → 앞으로 0.5 s」를 예측하는데, 명령이 1주기 늦게 들어가면 상태가 예측보다 늦게 따라와 다음 예측이 다시 「출발 직전」 상태를 봄 → 경유점에서 베이스 명령 ±0.04 m/s 진동 · 멈춤(함태훈 seed 2001 궤적)
- 10주차 대책(함태훈 제안 = B1 계획): ① 시연 · DART를 랜덤화 환경(`randomize.apply` + 테이블 ±10 mm · 지연 0 ~ 20 ms)에서 다시 수집 ② 관측에 직전 명령(지연 보상) · 손가락 접촉 ③ 평가는 함태훈 `bc_eval_pjj.py` 조건 그대로
